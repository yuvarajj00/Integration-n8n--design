# Media Publisher (BrandRelay / VelorQ)

Full-stack social media publishing platform integrated with **Cloudinary**, **FastAPI**, **Vue 3**, and **n8n** for multi-platform publishing (Instagram & Facebook).

## 🚀 Quick Start

For detailed step-by-step instructions with architecture diagrams and troubleshooting, refer to:
📖 **[RUN_GUIDE.md](./RUN_GUIDE.md)**

### Backend
```powershell
cd backend
.\venv\Scripts\activate
python run.py
```
API runs at `http://localhost:8000` (Docs at `http://localhost:8000/docs`).

### Frontend
```powershell
cd frontend
npm install
npm run dev
```
UI runs at `http://localhost:5173`.
